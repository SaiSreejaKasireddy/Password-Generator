# 🔐 Password Generator

A simple and user-friendly **Password Generator** web application built using **HTML, CSS, and JavaScript**. The application generates a random 16-character password containing uppercase letters, lowercase letters, and numbers.

## ✨ Features

- 🔑 Generates a random password with one click
- 🔢 Generates a 16-character password
- 🔤 Includes uppercase and lowercase letters
- 🔢 Includes numbers
- ⚡ Generates a new password instantly
- 🎨 Simple and clean user interface
- 💻 Runs directly in the browser

## 🛠️ Technologies Used

- **HTML5** – Used to structure the web page
- **CSS3** – Used for styling and layout
- **JavaScript** – Used for password generation and DOM manipulation

Password-Generator/

## ⚙️ How It Works

The application uses JavaScript to randomly select characters from a predefined character set containing:

- Uppercase letters (`A-Z`)
- Lowercase letters (`a-z`)
- Numbers (`0-9`)

The application generates 16 random characters and displays the resulting password on the webpage when the **Generate Password** button is clicked.

## 🚀 How to Run

### 1. Clone the repository

```bash

```

Navigate to the project folder:

```bash

```

### 3. Run the application

Open `index.html` in any modern web browser.
